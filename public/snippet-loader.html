Installation reference

The two-line SplitTag install

Put both lines in the page's <head>. The config must come first; the snippet must be a synchronous classic script.

1. Inline the running experiment config

<script>window.SPLITTAG_CONFIG = {"experiments":[{"id":"exp-hero-cta","targetUrlPattern":"/","trafficAllocation":1,"variants":[{"id":"control","weight":1,"changes":[]}],"goals":[{"id":"cta-click","type":"click","selector":"#cta-primary"}]}]};</script>

2. Load the pre-paint snippet

<script src="/snippet.js"></script>

No async, no defer, no bundler. The snippet hides the document immediately, assigns a variant locally with FNV-1a, applies the mutations, and reveals the page.

QA the variants

/?splittag_force=exp-hero-cta:control
/?splittag_force=exp-hero-cta:urgency

Force mode suppresses exposure and conversion events, so QA traffic never pollutes results.
